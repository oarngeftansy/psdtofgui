PSD → 旧 FGUI 视觉替换工具（联网测试版）

使用方法：
1. 将整个文件夹解压到本机普通目录，不要直接在压缩包中运行。
2. 双击“启动PSD替换工具.cmd”。
3. 第一次启动需要联网安装 Python 3.11 和本地处理依赖，等待时间取决于网络。
4. 浏览器自动打开后，导入旧 FGUI 工程 ZIP 和 PSD 开始处理。
5. 关闭启动工具的黑色窗口即可停止应用。

接收电脑：
- Windows 10/11 x64。
- 首次运行需要访问 winget 和 Python 软件包源。
- 不需要安装 Node.js，也不需要导入 Figma 插件。
- 应用依赖已锁定为本版本完成真实输出验证时使用的版本。
- 如需执行最终 FairyGUI 渲染验证，请另行安装 FairyGUI Editor。
- 请另行安装项目使用的字体；字体文件不包含在本应用包内。

本版本是开发测试版。默认静态视觉替换已经跑通；多个 Controller 页面、按钮状态、
Transition 中间帧等视觉映射规则尚未完全自动化，请在交付前人工审核候选工程。
