## 本轮已实现

- PSD 工作流的旧对象清单按实例路径递归展开；同一组件内同名对象不再和另一实例混淆。局部写入会回到实际组件文件，并换算坐标，处理 anchor；无法可靠处理的缩放、旋转、实例参数继续阻断。
- 对共享组件逐实例比较期望改动；不同资源或不同视觉属性不能覆盖成同一份定义。检查外部引用，并向受影响祖先传播：未选中页面间接使用该定义也会阻断。
- 用户明确允许 Delegate/Reward 的既有底图 graph 改为 image，游戏侧 GGraph 类型依赖另行验收。许可绑定项目指纹、组件路径、对象 ID 和旧文件 SHA-256；上传数据不能自行授予许可，其他 graph 仍拒绝转换。
- 写入保留原 ID、name、顺序及全部关系、gear、controller、transition、外层按钮实例。图像资源替换到原对象，不追加覆盖对象。审核差异包含 objectType 变化，禁止借转换篡改状态字段。
- 简单 PSD shape 可在严格检查路径、原始几何、父级混合、效果、蒙版、描边后转换为 native graph。本材料仅有 1 个 shape 符合条件。带装饰的按钮仍需可靠栅格视觉，不能退化成普通矩形。

- 声明的控制器状态按笛卡尔积枚举，超过验证预算时拒绝截断；状态比较包含像素变化方向，避免只比较变化区域大小而误放行。
