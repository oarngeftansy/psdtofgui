为避免 GUI 焦点和多实例噪声，真实 Editor 门禁使用一个单一中立代表工程；
其他类型由 XML golden 与自动化 gate 覆盖。

Editor 操作：

1. 解压验证后的 ZIP。
2. 用 FairyGUI Editor 6.1.4 打开 `GenericWriterFixture/GenericWriterFixture.fairy`。
3. 观察是否出现 repair/migration 或其他 modal。
4. 保存、关闭、重开、再保存；对比两次保存前后的已声明文件哈希。

## v1 保留边界

Project Binding、既有工程更新/资源复用、Controller/Gear/List 和没有自包含定义树的
组件引用均不在 Writer v1 范围内。

资源输入的编码字节限额为单文件 64 MiB、单次构建合计 256 MiB。目录加载在完整
读取前通过 regular-file handle/stat 尺寸和有界读取拒绝超限、稀疏或增长文件；内存
payload gate 在启动图片探测子进程前重新执行同样限额。
